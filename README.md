# VaikroChat
Website: www.vaikrochat.net
VaikroChat is a full-stack real-time chat application built with **React(Next.js)**, **Spring Boot**, **WebSocket**, and **AWS** technologies.  
This project demonstrates my skills in modern web development, scalable backend design, and interactive UI/UX.

---

## 🚀 Features

- **Real-Time Messaging:**  
  Instant chat updates using WebSocket (STOMP/SockJS) for seamless communication.

- **User Authentication:**  
  Secure login flow with JWT, demo mode for easy testing, and session management.

- **Private & Group Chats:**  
  Create, join, and manage private or group conversations with dynamic participant lists.

- **Profile Management:**  
  Update username, password, and profile images with robust backend validation.

- **Demo Mode:**  
  Guided walkthrough for new users, including auto-login with test accounts and interactive feature highlights.

- **File & Image Sharing:**  
  Upload and share images in chats, with S3-backed storage and secure access.

- **Responsive UI:**  
  Built with React and Tailwind CSS for a modern, mobile-friendly experience.

---

## 🛠️ Technologies Used

- **Frontend:** React, Next.js, Tailwind CSS
- **Backend:** Spring Boot, Hibernate, REST API, WebSocket (STOMP/SockJS) -- AWS EC2
- **Database:** PostgreSQL -- AWS DB
- **Storage:** AWS S3 for images
- **Authentication:** JWT
- **Testing & Demo:** Demo endpoints, guided tours, and test accounts

---

## 💡 Architecture Highlights

- **WebSocket Integration:**  
  Real-time updates for chat creation, deletion, and messaging, with per-user and per-chat subscriptions.

- **RESTful API Design:**  
  Clean separation of concerns with controllers for chat, account, message, and file management.

- **State Management:**  
  Context-based state in React for authentication, chat data, and demo mode.

- **Backend Data Seeding:**  
  Demo endpoints for resetting and populating test data, supporting interactive showcases.
